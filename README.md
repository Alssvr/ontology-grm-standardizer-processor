# 🏭 Обработчик онтологии ГРМ

Веб-интерфейс для обработки структурированных данных онтологии ГРМ. Принимает ZIP-архив с папками и возвращает обработанные справочники.

## ✨ Возможности

- 📤 **Загрузка ZIP-архива** с папками онтологии
- 🔍 **Автоматическое извлечение атрибутов** из Excel-шаблонов
- 🎯 **Точное сопоставление** атрибутов по 100% совпадению
- 📊 **Создание вспомогательных справочников** (отдельные файлы по атрибутам)
- ⚠️ **Статистика по отсутствующим атрибутам**
- 📥 **Архив с результатами** для скачивания

## 📁 Требуемая структура архива

Архив должен содержать следующую структуру:

Ваш_архив.zip/
├── Онтология ГРМ/ # Корневая папка
│ ├── Класс1/ # Папка класса
│ │ ├── Шаблон1/ # Папка шаблона
│ │ │ ├── Любое_название_Шаблон.xlsx # Файл шаблона
│ │ │ └── Любое_название_ПредЗап.xlsx # Файл записей
│ │ └── Шаблон2/
│ └── Класс2/



## 🚀 Как использовать

1. **Подготовьте данные**: Упакуйте папку "Онтология ГРМ" в ZIP-архив
2. **Загрузите архив**: Используйте форму на главной странице
3. **Запустите обработку**: Нажмите кнопку "Запустить обработку"
4. **Скачайте результаты**: Получите ZIP-архив с:
   - Отдельными файлами для каждого атрибута
   - Сводными данными
   - Статистикой обработки
   - Отчетом

## ⚙️ Технические детали

### Обрабатываемые атрибуты
- Извлекаются из строк 2-3 Excel-файлов
- От "Объект данных" до "Базовая единица измерения" (не включая)
- Исключаются системные атрибуты:
  - Код из системы источника
  - Наименование
  - Наименование из системы источника
  - Полное наименование

### Особенности обработки
- Сопоставление по 100% точному совпадению названий
- Автоматическое удаление дубликатов значений
- Поддержка кириллических названий
- UTF-8 кодировка всех файлов
